# Interactions & accessibility

Every live demo on this site is fully interactive — the points below apply to all of them.

## Mouse

- **Wheel** — zoom both axes around the cursor.
- **Drag the plot** — pan left/right (time) and up/down (price).
- **Drag the price axis** — rescale price; **drag the time axis** — rescale bar spacing.
- **Double-click** — reset scale (fit content + autoscale).
- **Hover a draggable order line** — the cursor switches to `ns-resize`, the line
  thickens and its pill brightens; the cancel `×` and DOM-ladder rows show a
  `pointer` cursor. Dragging shows a dimmed ghost at the pre-drag price (see
  [On-chart trading](/docs/trading#interaction-feedback-hover-drag-ghost)).

## Touch

Touch works out of the box (`touch-action: none` on the container):

- single-finger drag pans,
- **two-finger pinch** zooms,
- two-finger drag pans both axes.

## Keyboard & accessibility

The container is focusable (`role="application"`, `tabindex=0`, an `aria-label` you can
override) with a polite `aria-live` summary (bar count + latest price) that updates on data
changes. When focused:

| Key | Action |
|---|---|
| ← / → | pan time |
| ↑ / ↓ | pan price |
| + / − | zoom |
| Home / 0 | reset (`chart.resetScale()`) |

```ts
const chart = createChart(el, { ariaLabel: 'RELIANCE 5-minute candlestick chart' });
```

## Screenshots & grid

```ts
const canvas = chart.takeScreenshot();           // composites all panes + overlays → canvas
chart.downloadScreenshot('reliance-5m.png');     // same composite, downloaded as a PNG
chart.setGridOptions({ vertLines: false });      // toggle grid lines at runtime
```

<Callout type="info">
`takeScreenshot()` composites every pane and overlay layer into a single image, so the
result matches exactly what the user sees — useful for share/export buttons.
`downloadScreenshot(filename?)` wraps it in a PNG download (also bound to the
screenshot keyboard shortcut).
</Callout>

<Callout type="warning">
The browser's native right-click **"Save image as…"** captures only the topmost
canvas layer — the transparent crosshair overlay — because the chart renders as
stacked canvases. Always export via `takeScreenshot()` / `downloadScreenshot()`.
</Callout>
